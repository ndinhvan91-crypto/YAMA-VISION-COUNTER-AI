# YAMA Vision Counter AI VIP PRO

Ứng dụng web đếm người và đồ vật bằng AI (TensorFlow.js + COCO-SSD), giao diện Cyberpunk, chạy trực tiếp trên iPhone.

## Tính năng
- Nhận diện và đếm người, đồ vật theo thời gian thực
- Chuyển camera trước/sau
- Phân tích ảnh tải lên
- Xuất thống kê CSV

## Sử dụng
1. Mở link GitHub Pages bằng Safari (HTTPS)
2. Cho phép quyền camera
3. Nhấn Bắt đầu

## Công nghệ
HTML, CSS, JavaScript, TensorFlow.js, COCO-SSD
